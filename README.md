# ربات ارسال آگهی دیوار به تلگرام

رباتی برای جست‌وجوی خودکار آگهی‌های جدید دیوار و ارسال آن‌ها به کانال یا گروه تلگرام.

## وب‌سایت و پلن‌ها

صفحهٔ معرفی دیوار اسیست: **[aliaslany.github.io/divar-teleg-bot](https://aliaslany.github.io/divar-teleg-bot/)**

پلن‌های **رایگان، ماهانه و پرداخت به‌ازای مصرف** در این صفحه معرفی می‌شوند. برای تعرفهٔ پلن‌های پولی، هماهنگی راه‌اندازی و پشتیبانی با **[@Divarassist](https://t.me/Divarassist)** در تلگرام تماس بگیرید.

وب‌سایت استاتیک در `docs/` قرار دارد. برای اولین انتشار، در **Settings → Pages → Build and deployment** مقدار **Source** را روی **GitHub Actions** بگذارید؛ سپس Workflow **Deploy business website** را روی شاخهٔ `master` اجرا کنید. پس از آن تغییرات `docs/` روی `master` خودکار منتشر می‌شوند. این Workflow جدا از اجرای ربات است و به توکن تلگرام نیاز ندارد.

برای تغییر متن، پلن‌ها و پیوندهای فروش، `docs/index.html` را ویرایش کنید. استایل‌ها در `docs/styles.css` و فهرست موبایل در `docs/site.js` هستند. فونت محلی Vazirmatn تحت مجوز SIL OFL 1.1 همراه با مجوز اصلی در `docs/assets/OFL.txt` قرار دارد.

## امکانات

- جست‌وجوی آگهی‌های جدید در یک یا چند شهر
- فیلتر بر اساس دسته‌بندی دیوار
- ارسال خودکار جزئیات و تصاویر آگهی به تلگرام
- تولید خودکار هشتگ‌های مرتبط
- بررسی اختیاری آگهی‌های حذف‌شده یا اجاره/فروش‌رفته
- امکان تغییر فیلترها از طریق دستورات ادمین
- اجرا با GitHub Actions بدون نیاز به سرور یا VPS
- ذخیره وضعیت آگهی‌های ارسال‌شده برای جلوگیری از ارسال تکراری

## نحوه عملکرد

ربات به‌صورت زمان‌بندی‌شده توسط GitHub Actions اجرا می‌شود:

1. آگهی‌های جدید دیوار را بررسی می‌کند.
2. آگهی‌های قبلاً ارسال‌شده را شناسایی می‌کند.
3. آگهی‌های جدید را همراه با جزئیات، تصویر و هشتگ به تلگرام می‌فرستد.
4. وضعیت را ذخیره می‌کند تا در اجرای بعدی آگهی تکراری ارسال نشود.

## راه‌اندازی سریع

در بخش **Settings → Secrets and variables → Actions** این مقادیر را تنظیم کنید:

- `BOT_TOKEN` : توکن ربات تلگرام
- `BOT_CHATID` : شناسه کانال یا گروه مقصد
- `SEARCH_CITY_IDS` (اختیاری): شناسه شهرها با کاما، مانند `823,1996,1999`؛ مقدار پیش‌فرض `897`
- `SEARCH_CATEGORY` (اختیاری): دسته‌بندی دیوار؛ مقدار پیش‌فرض `real-estate`

مقادیر خالی فیلترهای اختیاری از پیش‌فرض استفاده می‌کنند. خالی بودن `BOT_TOKEN` یا `BOT_CHATID` باعث توقف اجرا با نام متغیر موردنیاز می‌شود.

سپس در تنظیمات GitHub Actions، دسترسی **Read and write permissions** را فعال کنید و Workflow را اجرا نمایید.

Workflow وضعیت را روی همان شاخه‌ای ذخیره می‌کند که اجرا شده است. اگر ارسال برخی آگهی‌ها موفق باشد و اجرا بعداً خطا بدهد، وضعیت ارسال‌های موفق همچنان ذخیره می‌شود. خطای push یا تعارض Git اجرای ناموفق را نشان می‌دهد و یک کپی بازیابی از `tokens.json` در بخش Artifacts نگه می‌دارد؛ پس از رفع تعارض می‌توان از آن برای بازیابی وضعیت استفاده کرد.

برای اجرای محلی، از Python 3.11 استفاده کنید، وابستگی‌ها را با `python -m pip install -r requirements.txt` نصب کنید و متغیرهای محیطی را مطابق `.env.sample` تنظیم کنید. سپس `python main.py` را اجرا کنید. برنامه فایل `.env` را خودکار بارگذاری نمی‌کند.

آزمون‌های آفلاین با `python -m unittest discover -s tests -v` اجرا می‌شوند و به توکن واقعی یا ارسال پیام نیاز ندارند.

## فناوری‌ها

- Python
- Telegram Bot API
- GitHub Actions
- API غیررسمی دیوار

## ساختار پروژه

- `main.py` : اجرای اصلی ربات
- `divar_client.py` : دریافت اطلاعات آگهی‌ها از دیوار
- `telegram_client.py` : ارسال پیام به تلگرام
- `hashtags.py` : تولید هشتگ‌های مرتبط
- `storage.py` : ذخیره وضعیت آگهی‌ها
- `.github/workflows/run-bot.yml` : اجرای زمان‌بندی‌شده با GitHub Actions

## نکته

این پروژه از API غیررسمی دیوار استفاده می‌کند و در صورت تغییر API یا ساختار وب‌سایت ممکن است نیاز به به‌روزرسانی داشته باشد.
